Morse Da

▸ HOW TO USE MORSEDA ◂

1. What is Morse Da

Morse Da is a Morse code training tool built around amateur radio contest CW contacts. It runs entirely in your browser — no installation or account required — and works on both PC and smartphone.

This page walks through every feature and how to use it, whether you're new to Morse Da or want a refresher.

2. Home Page

Visit https://jl1gix.com/index-en.html to see the mode selection screen. Choose one of the following modes to start.

  • Receive Mode: Listen to CW tones from your speakers and type what you hear on the keyboard
  • Transmit Mode: Convert the characters shown on screen into Morse code using the keyboard or a paddle
  • Fun Mode: Same controls as Transmit Mode, but with familiar English words as the material for casual play

From the bottom of the page you can also access the Ranking, the Morse Code Table, and other learning content.

3. How to Use Receive Mode

Settings Screen

Once you enter Receive Mode, you can configure the following:

  • Time Limit: Choose 1, 3, or 5 minutes
  • Morse Speed (WPM): Choose from 20 to 30 WPM in 1 WPM steps (default 25 WPM)
  • Beginner Mode: Shows the Morse code for the character currently being sent, in real time. Turning it on adds a "beginner" mark when you register your score

Audio Check

Checking "🔊 Audio Check" at the top right loops the SOS pattern (・・・−−−・・・) so you can adjust your headphone or speaker volume and check the sound quality. Changing the WPM automatically adjusts the SOS playback speed to match.

Starting the Game

Clicking "▶ START MISSION" plays a callsign and an RST report alternately, in audio.

  • Callsign example: JL1GIX, 7K1ABC, 8J1RL/1
  • RST example: 599108H (599 + prefecture code 108 + suffix letter). The leading "599" is conventionally sent as "5NN" outside Beginner Mode, but typing either 599 or 5NN counts as correct (in Beginner Mode it is always sent as 599, and only 599 counts as correct)

Type what you heard into the input field at the bottom of the screen and press Enter to check it. If correct, you move to the next item; if wrong, the screen flashes red and the same item continues.

Scoring

Your score is simply the number of characters you get right. You compete on how many you can correctly answer within the 1, 3, or 5 minute time limit.

QUIT Button

You can stop before the time limit is up using the QUIT button. Quitting resets your score and it will not be registered to the ranking.

4. How to Use Transmit Mode

Keyboard Controls

On desktop, you can use keyboard keys as a CW keyer.

  • Dot (・): Space key by default (changeable from "⌨ Key Settings")
  • Dash (−): J key by default (changeable from "⌨ Key Settings")
  • Hold for repeats: Holding a key down sends a continuous stream of dots or dashes via the Iambic keyer
  • Squeeze with both keys: Holding both keys at once automatically alternates dots and dashes (Iambic mode)

Paddle Buttons (Phone/Tablet)

On touch devices, two buttons labeled "DIT" and "DAH" appear at the bottom of the screen.

  • Tap: Sends a single dot or dash
  • Hold: Sends continuously (same behavior as the PC keyboard)
  • Hold both at once: Automatically alternates in Iambic mode, same as PC

Decode Timing

After you finish keying and a set time passes (roughly 2x a dit on desktop, roughly 5x on mobile), Morse Da automatically decodes your input into a character. If correct, you move to the next character; if wrong, the screen flashes red and you key it again.

Beginner Mode

As in Receive Mode, turning this on shows the Morse code for the character you're about to key. Useful while you're still learning the codes.

Keying the Contest Number (RST)

The RST is presented with a leading "5NN", like "5NN108H", and only keying 5NN counts as correct. For contest number digits, keying 1 as "1" or "A", 0 as "0", "O", or "T", and 9 as "9" or "N" all count as correct (cut numbers). Callsign digits, however, only count as correct when keyed as the actual digit.

5. Fun Mode

Enter from "🎮 Fun Mode" on the home page. The controls are the same as Transmit Mode, but instead of callsigns and RST reports, the material is familiar English words like CAT or DOG.

  • Each word has its own time limit, and you must finish keying it before the "📡 SIGNAL" bar at the bottom runs out (if you don't make it, the signal fades (QSB), the word is lost, and play moves to the next word)
  • The time limit adjusts automatically based on the word's length and your WPM setting
  • Keying a word with zero mistakes extends your overall play time by 1 second (a "+1s" effect appears next to the TIME display)
  • As in Receive and Transmit modes, your score can be registered to the ranking

6. Free Input Mode (inside Transmit Mode)

Choosing "📝 Free Input Mode" from the Transmit Mode settings screen lets you key freely and hear the tones without any assigned material.

  • No target text is shown — key whatever characters you want
  • Decoded characters appear on screen in real time
  • The dots and dashes you keyed are also shown, so you can check whether your keying was correct

Handy as a stand-in for real equipment when practicing your keying, checking your tone, or memorizing new characters.

7. Ranking Feature

After a game ends, submitting your score registers it to the ranking (tallied separately for Receive, Transmit, and Fun modes).

Registering a Nickname

  • Enter **only uppercase A-Z letters and digits 0-9** into the field (up to 10 characters)
  • Confirm with the "✏️ Set Name" button or the Enter key
  • If left blank, you'll be registered as "noname"

Viewing the Ranking

From "Ranking" in the footer, you can view top scores broken down by mode (Receive/Transmit/Fun) and time limit (1/3/5 min). Your own standing is also shown as a percentile.

8. Troubleshooting

  • No sound plays: Browser autoplay policies require an initial click. Audio is enabled the moment you press "▶ START MISSION". If you still hear nothing, check your browser's or OS's volume settings.
  • Transmit Mode isn't decoding my input: Uneven dot/dash length or spacing prevents recognition. Try lowering the WPM to keep a steady rhythm, aim for a dash about 3x a dot, and leave a bit more space between characters.
  • My score wasn't registered: Scores aren't registered if you QUIT mid-game. Play until the time limit runs out.
